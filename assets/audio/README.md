# Included sound tests

`fart.wav` and `fart-youtube-*.wav` are CC0 YouTube-origin effects from a verified
Wikimedia archive. See [SOURCES.md](SOURCES.md) for the source, license, archive
identity and editing steps. The original YouTube URL is no longer available.
`fart-synthetic.wav` and `burp.wav` are original procedural effects generated by
`generate.py` with deterministic oscillators and seeded noise.

These demonstration effects may be redistributed with the application source.
Confirmed Chuddy fart playback earns one score with speaker provenance.
`burp.wav` is retained as an offline negative fixture and a legacy Pi echo
reference. The acoustic classifier uses the known WAV and capture timing to
subtract a matching echo.
Separate sounds remain eligible for acoustic scoring during playback. Acoustic
accuracy remains uncalibrated. See the [audio guide](../../docs/VOICE.md) for classifier checks.

Regenerate procedural effects without playback: `python assets/audio/generate.py`.
This preserves the YouTube-origin default fart. Extract archive variants with
`python assets/audio/import_youtube.py SOURCE.wav`.
