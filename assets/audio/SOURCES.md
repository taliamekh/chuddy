# Sound attribution and reuse

## YouTube-origin fart effects

`fart-youtube-*.wav` and the default `fart.wav` are edited excerpts from **Farting
sound effects**, published at
https://www.youtube.com/watch?v=r6QrycdtnOo and archived on
[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Farting_sound_effects.webm).
The original YouTube URL reported unavailable.
The verified archive was used for these YouTube-origin sounds; this is not a claim
that the original YouTube download is still live.

The Commons file page identifies the author as “Public domain” and explicitly
licenses the file under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
It was uploaded there by Atsme. Original archive URL:
https://upload.wikimedia.org/wikipedia/commons/e/e3/Farting_sound_effects.webm

The downloaded 794,730-byte source matched the published SHA-1
`0ed3b3cab89f3ca0dd069cb0bb5ba94cff446e3a` before conversion. Edits: mono 24 kHz
PCM conversion, silence trimming, peak level reduced to 0.75, short fades and
individual regions. `youtube-variants.json` records excerpt positions/durations.
No sound was played or microphone activated during extraction or inference checks.

Rebuild the excerpts from the converted source WAV with
`python assets/audio/import_youtube.py SOURCE.wav`. The source download is retained
locally in ignored `.chuddy/audio-sources`, not required to run the included WAVs.

## Procedural effects

`burp.wav` and `fart-synthetic.wav` were generated by this project's `generate.py`
using deterministic oscillators and seeded noise. They contain no third-party
recordings. The synthetic fart is retained as a fallback/reference; the default
fart effect now uses the licensed YouTube-origin archive above.

## Local auditions excluded from distribution

The Patrick reference is local only; see `docs/VOICE.md`. An additional live fart
effect audition, **Fart (Long)** by Awesome Sound FX
(https://www.youtube.com/watch?v=8xrJDdYSnmc), was checked. Its description claims
“Creative Commons Attribution license (reuse allowed)”, but the retrieved license
metadata was empty and the version/original ownership was not established. It is
kept only as an ignored local audition and is not included in distributable assets.
